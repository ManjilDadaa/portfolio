Project note

E-commerce Platform

A full-stack storefront study: React on the front, Node.js and Express on the back, with MongoDB for storage and Stripe for payments. Built to learn how a catalog, a cart, and an order pipeline fit together end to end.

What it does

  • Responsive storefront for mobile and desktop
  • Account sign-up, sign-in, and role-based authorization
  • Product catalog with search and filtering
  • Cart and checkout flow
  • Order management and an admin dashboard

Stack

  • React with Redux for state
  • Node.js and Express
  • MongoDB
  • Stripe for payment processing
